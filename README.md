# ***bakery-app***

Пет-проект сделан для потребителей кондитерских изделий, экран быстрой загрузки с анимацией при старте, динамическая маршрутизация с react-router-dom...

## СТЕК ПРИЛОЖЕНИЯ - Git, Node.js v24, vite v8, react v19, react-router-dom v7, typescript v5, CSS Modules

# ЗАПУСК ПРИЛОЖЕНИЯ ПО ШАГАМ

#1. git clone (ссылка на репозиторий)

#2. cd (папка репозитория)

#3. npm install

#4. npm run dev
